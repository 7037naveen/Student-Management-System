# Student Management System

A web-based Student Management System developed using PHP and MySQL.

## Features

- Admin Login
- Add Student Records
- Update Student Details
- Delete Student Records
- Search Student
- Database Management

## Technologies Used

- PHP
- MySQL
- HTML
- CSS
- JavaScript

## How to Run

1. Install XAMPP Server
2. Copy project folder into htdocs
3. Start Apache and MySQL
4. Import database.sql into phpMyAdmin
5. Open browser and run:

localhost/Student-Management-System
